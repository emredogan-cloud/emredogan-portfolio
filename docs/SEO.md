# SEO — what is emitted, and what is deliberately not

**Last audited:** 2026-08-19, against the production build.

---

## Metadata

Every route builds its metadata through `lib/utils/seo.ts`, so title template,
canonical, Open Graph and Twitter card cannot drift apart per page.

| Route          | Canonical                            | Title                                  |
| -------------- | ------------------------------------ | -------------------------------------- |
| `/`            | `https://emredogan.work`             | Emre Doğan — Full-Stack & AI Developer |
| `/about`       | `https://emredogan.work/about`       | About — Emre Doğan                     |
| `/work`        | `https://emredogan.work/work`        | Work — Emre Doğan                      |
| `/work/[slug]` | `https://emredogan.work/work/<slug>` | _Project_ — Emre Doğan                 |

- `lang="en"` on every page; the site is English-only, so no `hreflang`.
- Open Graph images are generated by `next/og` at 1200×630 — one for the site
  and one per case study.
- Twitter card: `summary_large_image`.

## Structured data

| Page           | Types                                                           |
| -------------- | --------------------------------------------------------------- |
| `/`            | `Person` + `WebSite` in one `@graph`, cross-referenced by `@id` |
| `/work/[slug]` | `CreativeWork` + `BreadcrumbList`                               |

`Person` carries name, URL, email, job title, description, `PostalAddress`,
`sameAs` for the two public profiles, `knowsAbout`, and a single
`ContactPoint` — **email only**.

### What is deliberately absent

- **No `telephone`.** No phone number is published anywhere on this site, so
  none is claimed in structured data either. Machine-readable claims are claims.
- **No `SearchAction`.** §9 of the roadmap lists `WebSite` + `SearchAction`, and
  the pattern requires a URL template pointing at a working search endpoint.
  This site has no search. Declaring one is how a site ends up with a Google
  sitelinks search box that leads nowhere.
- **No `Organization`, `alumniOf`, `worksFor` or `award`.** There is no
  employer, no institution and no award to name, and inventing one in JSON-LD
  is the same lie as putting it on the page.
- **No `AggregateRating` or `Review`.** There are no reviews. The site says so
  in prose rather than fabricating the markup.

Validated by parsing every emitted block and asserting its shape in
`tests/e2e/home.spec.ts` and `tests/e2e/work.spec.ts`. Google's Rich Results
Test needs a public URL and is run against production in Phase 14.

## Crawling

`robots.txt`, generated from `app/robots.ts`:

```
User-Agent: *
Allow: /
Disallow: /dev/

Host: https://emredogan.work
Sitemap: https://emredogan.work/sitemap.xml
```

`/dev/` holds the token gallery, which is a development surface and has no
business in an index.

`sitemap.xml` is derived from the content modules — **11 URLs**: the three
pages plus one per project. It cannot fall out of step with the site, because
adding a project adds its sitemap entry.

## Rendering

Every route is **statically prerendered**, so a crawler receives complete HTML
with no JavaScript execution required. `generateStaticParams` with
`dynamicParams = false` means an unknown project slug is a real 404 rather than
a soft one.

## Measured

Lighthouse SEO: **100** on `/`, `/about`, `/work` and `/work/pawdoc`, on both
desktop and mobile. See `docs/PERFORMANCE.md`.
